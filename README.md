# VisionAssist - Low Vision & RP Accessibility Assistant

Designed specifically for users with **Retinitis Pigmentosa (RP)** and low vision.

---

## ⌨️ Active Keyboard Shortcuts

| Shortcut | Action | Auditory Feedback |
| :--- | :--- | :--- |
| **`Ctrl + *`** | **Toggle Red Cursor** <br>*(Switches between High-Visibility Red & Standard)* | 🎶 Rising Tone (On) / Falling Tone (Off) |
| **`Ctrl + /`** | **Toggle Cursor Size** <br>*(Cycles Standard 32px ➜ Large 64px ➜ Extra Large 96px)* | 🔔 High Pitch Beep (Enlarge) / Low Pitch Beep (Normal) |
| **`Ctrl`** *(Single tap)* | **Radar Locator** *(Emits radiating circles around pointer)* | Visual radar |

> **Key Details:**
> - **`Ctrl + *`**: Works with Numpad `*` or main row `Shift + 8`.
> - **`Ctrl + /`**: Works with Numpad `/` or main row `/?`.
